# Flutter Blue 蓝牙状态监听机制文档

## 概述
Flutter Blue 插件实现了跨平台的蓝牙状态监听功能，当用户手动关闭蓝牙时，能够主动向 Dart 端发送事件通知。

## 平台实现细节

### Android 端实现
- **文件位置**: `android/src/main/java/com/pauldemarco/flutter_blue/FlutterBluePlugin.java`
- **核心机制**: 
  - 使用 `EventChannel` 创建 `stateChannel`
  - 通过 `BroadcastReceiver` 监听 `BluetoothAdapter.ACTION_STATE_CHANGED` 广播
  - 在 `onReceive()` 方法中处理状态变化并通过 `EventSink` 发送事件

### iOS 端实现
- **文件位置**: `ios/Classes/FlutterBluePlugin.m`
- **核心机制**:
  - 使用 `EventChannel` 创建 `stateChannel`
  - 通过 `CBCentralManagerDelegate` 的 `centralManagerDidUpdateState` 方法监听状态变化
  - 将 `CBManagerState` 映射为 Protobuf 消息并发送

## Dart 端使用示例

### 基本监听方式
```dart
import 'package:flutter_blue/flutter_blue.dart';

// 监听蓝牙状态变化
StreamSubscription<BluetoothState> subscription = 
    FlutterBlue.instance.state.listen((state) {
  if (state == BluetoothState.off) {
    print('蓝牙已关闭');
  } else if (state == BluetoothState.on) {
    print('蓝牙已开启');
  }
});

// 取消监听
subscription.cancel();
```

### 状态枚举值
- `unknown` - 未知状态
- `unavailable` - 蓝牙不可用
- `unauthorized` - 未授权
- `turningOn` - 正在开启
- `on` - 已开启
- `turningOff` - 正在关闭
- `off` - 已关闭

### 实际应用模式
```dart
// 在 Widget 中使用
class BluetoothMonitor extends StatefulWidget {
  @override
  _BluetoothMonitorState createState() => _BluetoothMonitorState();
}

class _BluetoothMonitorState extends State<BluetoothMonitor> {
  BluetoothState _currentState = BluetoothState.unknown;
  
  @override
  void initState() {
    super.initState();
    FlutterBlue.instance.state.listen((state) {
      setState(() => _currentState = state);
    });
  }
  
  @override
  Widget build(BuildContext context) {
    return Text('蓝牙状态: $_currentState');
  }
}
```

## 注意事项
1. 记得在不需要时取消订阅，避免内存泄漏
2. 监听状态变化是实时推送的，无需轮询
3. 不同平台的状态转换可能有细微差异
4. 建议在应用启动时就建立监听，确保及时响应状态变化
